# kr0 Game Studio

Design documents, prototypes and art for kr0 Game Studio's games: Blackletter, Dropfront, Dual Tech and Metr0niks.

- `studio/`: rules for every game. Start with [studio/README.md](studio/README.md).
- `games/<name>/`: each game's pitch, GDD, TDD, decisions and prototype, with research, simulations, prototypes, feedback and artifacts folders.
- `art/<name>/`: each game's art.
- `tools/`: tools shared by every game.
- `site/`: the public studio site.
- [studio/design-workflows.md](studio/design-workflows.md): how characters and sprites are made (Scenario workflows and MCP servers).
- [INDEX.md](INDEX.md): every document, with status.
