# Metr0niks GDD decision history

Newest first. Status is Proposed until kr0 accepts or rejects it. The [GDD](gdd.md) holds the rules; this file records the choices behind them so debates don't repeat. The reviews that raised each question are in [reviews/](reviews/SYNTHESIS.md). Decisions made on 2026-10-20 are in the table in [open questions](open-questions.md) and are not repeated here.

| GDD-D24 | 2026-10-26 | Extracting level 50 wins the campaign with a victory screen whose button starts a new campaign at level 1, keeping parts, upgrades and banked scrap. | GDD-D23 | 2026-10-26 | Scrap pays for parts, weapon upgrades and repairs; there are no raw stat upgrades, since base stats come from the frame and parts change them. This changes GDD-D16 | Accept the GDD-D16 cut (parts and repairs only); higher-tier copies of each weapon; buying a better part counts as the upgrade; arm weapons only | kr0: players pay for repairs, different weapons and weapon upgrades, with no raw stat upgrades; shoulder actives included. A second repeatable sink besides repairs. Values are starting values for a sweep (tuning history) | Applied; values accepted by kr0 on 2026-10-26 as starting values for the sweep | kr0 |
| GDD-D22 | 2026-10-25 | No touch controls: the platform is PC with keyboard and mouse. The prototype's touch UI is to be removed | Add touch to the platform | Matches the decided platform; the GDD describes only keyboard and mouse | Applied | kr0 |
