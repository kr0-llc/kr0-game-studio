Tim-o guided run

A run cycle made without the Action Sprite Studio workflow. I wrote the frame plan myself, drew a pose guide sheet in code, and sent my prompt to the image model word for word with the turnaround as the first reference. The same prompt and references went to two models. The Oct 28 isometric run is here as the baseline.

The method

  1. Frame plan written by hand. Eight beats, contact, down, passing and up for each leg. No LLM step rewrites it.
  2. Pose guide sheet. art/metr0niks/source/pose_guide.py draws one cell per frame: the ground footprint, a height line, and a blue stick rig with knees, feet, torso, pack and both gun arms. Dark blue is the near (right) side, light blue the far (left) side. It goes in as the second reference.
  3. References in order. The four-view turnaround first (identity), the guide second (pose and placement).
  4. Pinned settings. 1536 × 1024, quality medium, transparent background for Sunburst; 2K, 3:2, thinking high for Gemini.
  5. Local slicing and measuring. art/metr0niks/source/sheet_frames.py cuts the cells, keys white, lines every frame up on the body centre and the ground, and reports height spread and drift.
  6. Run record. Every call is in art/metr0niks/prompts/tim-o-sprites-run-iso-guided.txt.
